One word, first thought. The entry is a single word — no topic, no
explanation, no second draft.

## The word

**defenestration**

## Why this word

It is the first word that comes to mind when the mind is allowed to wander
somewhere strange: a single word that paints a whole scene — someone, a
window, a sudden exit — and sounds like a joke being told in a library.
Surprising, vivid, and just witty enough to beat a safe word head to head.

## Run it

```sh
node main.ts
```

It writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is unset).
